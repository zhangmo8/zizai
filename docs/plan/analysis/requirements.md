# 需求分析

Status: Draft（v2：存储改 SQLite、编辑器改所见即所得）
范围：字在（ZiZai）—— 个人自用沉浸式码字 App

## 1. 背景与目标

- 使用者：仅作者本人（单用户，无账号、无云同步需求）。
- 动机：需要一个「打开就写」的本地写作工具，覆盖桌面（Windows/macOS）与手机（Android）。
- 核心体验：**所见即所得**——写什么就看到什么，不存在「源码 vs 预览」的两层心智；**打开就写，写完就走，数据在自己手里**。
- 成功标准：从「想写」到「写起来」不超过 2 次点击；写的东西永远不丢。

## 2. 用户场景

| # | 场景 | 期望 |
|---|---|---|
| S1 | 打开 App 继续写 | 自动定位到上次编辑的文档，直接进入写作 |
| S2 | 沉浸式码字 | 隐藏一切干扰，全屏纯编辑，实时字数在视线内 |
| S3 | 管理一本书的章节 | 笔记本 + 章节树，新建/重命名/删除/调整顺序 |
| S4 | 每天有进度感 | 今日已写字数 vs 目标，状态栏可见 |
| S5 | 碎片时间（安卓）写一段 | 竖屏、单手可用、自动保存、随时退出 |
| S6 | 排版所见即所得 | 标题/加粗/列表等直接渲染成效果，无独立预览 |
| S7 | 换字体/换主题 | 浅色/深色/跟随系统；字体、字号、行距可调 |
| S8 | 换设备继续写 | 手机写一段，电脑打开接着写，云同步自动完成 |
| S9 | 升级不丢数据 | 新版本自动迁移数据库，升级前后数据一致 |

## 3. 功能需求

### F1 文档管理
- F1.1 库（Library）= SQLite 数据库（`zi-zai.db`），含全部笔记本、文档、设置、统计。
- F1.2 笔记本（Notebook）= 一个写作项目（书/文集），库内记录。
- F1.3 文档（Document）= 一章/一篇，内容为富文本（Quill Delta JSON），库内记录。
- F1.4 文档 CRUD：新建、重命名、删除、在笔记本内移动。
- F1.5 排序：库内 `position` 字段；菜单提供「上移/下移」；拖拽排序 V2（backlog）。
- F1.6 数据安全出口：导出当前文档为纯文本（.txt）；整库备份 = 复制 db 文件。

### F2 编辑（所见即所得）
- F2.1 富文本编辑：标题 H1–H3、加粗、斜体、下划线、删除线、无序/有序列表、引用、行内代码、代码块。**渲染即所见，无独立预览模式。**
- F2.2 自动保存：输入防抖 1s；失焦、切换文档、退出时立即保存。
- F2.3 撤销/重做（编辑器内置）。
- F2.4 V1 不支持：图片粘贴、链接、表格、分页符（backlog）。
- F2.5 上下文工具栏：选中文本时浮现格式化操作（Notion 式），平时不占界面。

### F3 字数统计
- F3.1 实时字数：以文档纯文本计——中文按字符，连续英文/数字按词；状态栏显示。
- F3.2 每日目标：可配置目标字数；今日增量累计，状态栏显示进度条。
- F3.3 增量规则：每次保存用「本次字数 − 上次保存字数快照」累计到当日（见 [app/README.md](../../app/README.md#增量规则)）。

### F4 沉浸模式
- F4.1 隐藏侧边栏、工具栏、状态栏，编辑器占满可用空间。
- F4.2 退出机制分平台：桌面 `Esc` / 顶缘悬停条；**Android 系统返回手势/返回键为主**，顶部 48px 热区（点按弹「退出+字数」条、下滑直接退）兜底——移动端无 Esc，不允许把退出寄托在键盘上。
- F4.3 沉浸模式内选中文本 → 浮动工具栏照常可用（不退出沉浸）。
- F4.4 打字机滚动（当前行居中）——V2（backlog）。

### F5 设置
- F5.1 主题：跟随系统 / 浅色 / 深色。
- F5.2 字体：编辑器字体族、字号、行距。
- F5.3 每日目标字数。
- F5.4 导出当前文档为 .txt；显示 db 文件路径（备份指引）。
- F5.5 库位置：db 存于应用支持目录，桌面端可打开所在目录。

### F7 云同步（CF 存储为基准：R2，opt-in）
- F7.1 设置页开启/关闭；token 由用户配置；**默认关闭**，不配置则完全离线。
- F7.2 文档级增量同步：新建/修改/删除（tombstone）；启动拉取 + 保存防抖 30s 推送 + 手动「立即同步」。
- F7.3 冲突策略：文档级 LWW；输家版本写本地 `.sync-bak/`（保留 5 份）；R2 版本控制留云端历史。
- F7.4 状态栏同步状态指示；失败指数退避重试，不阻塞写作。
- 协议与 blob 结构见 [sync.md](../../app/sync.md)。

### F8 更新与版本
- F8.1 App 版本号（pubspec）展示在设置页「关于」。
- F8.2 DB schema 版本（`PRAGMA user_version`）+ 有序迁移链；升级前自动备份（滚动 3 份）；迁移失败停止启动并提示。
- F8.3 更新检查：R2 清单 `update.json`；sha256 校验；提示式安装（Android 系统安装 / 桌面解压替换）。
- F8.4 同步协议版本协商：不兼容 → 409 → 升级提示。
- 详见 [update.md](../../app/update.md)。

### F9 平台要求
- F6.1 桌面（Win/macOS）：全窗布局、快捷键、可调窗口。
- F6.2 Android：竖屏优先、Drawer 侧边栏、工具栏折叠、沉浸模式全屏。

## 4. 非功能需求

| 项 | 要求 |
|---|---|
| 数据安全 | 单库文件；保存失败必须有可见错误与重试入口；打开时校验 db 完整性（损坏 → 提示并从备份恢复） |
| 性能 | 冷启动到可编辑 ≤ 2s；文档加载只取当前文档行，不整库读入 |
| 崩溃恢复 | 启动时检测未保存缓冲（内存快照），可恢复 |
| 离线 | 无网络依赖 |
| 体积 | 不内置大字体资源（V1 用系统字体） |

## 5. 范围

**V1 包含**：F1–F5、F9。
**V1 明确不做**：
- 图片/附件粘贴（Markdown 引用图片不渲染）
- 实时协同/多人协作（单用户）
- 全文搜索（V2）
- 导出整库为 Markdown 文件集（V2；V1 提供单文档纯文本导出 + db 文件备份）
- 拖拽排序、打字机滚动、焦点模式（V2，backlog）
- 云端修订历史浏览/回滚 UI（V2；数据层面 R2 版本控制已留）

**V1 范围内的排序**（里程碑见 docs/plan/README.md）：
1. M1–M3 核心写作（本地完整可用，等价于无云版）
2. M4 云同步（F7）+ 更新机制（F8）
3. M5 打磨打包

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 富文本数据封闭在 db 里 | V1 提供单文档导出 + 整库文件备份；V2 补全库导出 md |
| 中文字体跨端渲染差异 | 设置只列系统字体，字号/行距可调兜底 |
| 增量统计丢失（写一半退出） | 防抖 1s + 失焦/退出立即保存；字数快照随保存落库 |
| Quill 编辑器桌面/移动行为差异 | 工具栏同一组件，桌面自动收起为快捷键，移动端折叠面板 |
| 同步冲突丢字 | 输家版本 `.sync-bak` 本地保留 + R2 版本控制可回滚（见 sync.md §5） |
| 迁移失败损坏数据 | 升级前 `.bak` 备份 + 迁移失败停止启动提示（见 update.md §2） |
| token 泄露 | 自配 token 可轮换；HTTPS；Worker 不记内容日志；token 永不随同步推送 |
