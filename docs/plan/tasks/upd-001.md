## Objective

按 docs/app/update.md 实现更新机制与版本体系落地：

1. `core/update.dart`：
   - 拉取 R2 `update.json`（URL 来自设置，可配置）；
   - 版本比较（语义化，跳过旧版本）；`minDbSchema` 读取；
   - 下载安装包 → sha256 校验（不符拒绝安装并报错）→ 平台安装：
     - Android：FileProvider 触发系统安装；
     - 桌面：解压 zip 替换应用目录（macOS 未签名 app 首次「右键打开」提示写入文档）。
2. DB 版本落地：`store-001` 的迁移链框架接入启动流程；启动时若本地 `user_version` < 代码版本 → 先备份再逐级迁移；迁移失败 → 停止启动 + 明确错误。
3. 设置页「关于」区：App 版本（pubspec）、DB 版本（`user_version`）、「检查更新」按钮（发现新版 → accent 徽标 + 确认下载 + 进度 + 安装）。
