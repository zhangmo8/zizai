## Objective

打通导入方向（现仅有纯文本导出）：

1. `core/import_markdown.dart`：Markdown 文本 → Quill Delta
   - 覆盖编辑器已支持的块/行内格式：H1–H3、无序/有序列表、引用、待办、代码块、
     加粗/斜体/行内代码/删除线（与 ui-editor.md §快捷块一致的子集）；
   - 不支持的语法（表格、图片、链接等）降级为纯文本保留内容，不丢字；
   - 纯函数 + 单测基准（样例 md → 期望 Delta）。
2. UI 入口：侧边栏笔记本 `⋮` 菜单「导入 Markdown」→ 文件选择（桌面 file_selector /
   Android 系统文件选择）→ 每个 `.md` 文件建一篇文档（文件名为标题）→ 导入结果 toast。
3. 顺手补齐 backlog #2 的反向出口可另立任务，本任务只做导入。
