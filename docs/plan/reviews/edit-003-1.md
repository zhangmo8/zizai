## 非阻塞发现（建议追加 backlog）

1. **桌面工具栏定位**（偏差①延续）：固定编辑器区顶部（editor.dart:318-324），非「选区上方」；flutter_quill 公开 API 无选区屏幕坐标，建议后续用选区 rect 估算或升级 quill 能力实现桌面浮动定位。
2. **桌面 `Ctrl/Cmd+B` 快捷键冲突**：ui-shell.md「Ctrl/Cmd+B 切换侧边栏」vs ui-editor.md「Ctrl/Cmd+B 加粗（编辑器内置）」——Shell HardwareKeyboard 先消费（shell.dart:73-76），桌面端键盘加粗失效（工具栏可用；`Ctrl+I/U` 走 quill 内置正常）。属设计文档间冲突，实现取 ui-shell.md 合理；建议文档裁决或 Shell 在编辑器持有焦点时放行（放行需注意 quill 默认即绑 Cmd+B）。
3. **Windows `Ctrl+S` 保存快捷键被遮蔽**：flutter_quill 11.5.1 内置默认把 `Ctrl+S`（control 路径，非 macOS）映射为 codeBlock toggle（`default_single_activator_intents.dart`），Shortcuts 就近解析使 EditorView 外层 `_SaveIntent` 失效——macOS 下 `Cmd+S` 正常（quill 仅绑 control，测试已证），Windows 下 `Ctrl+S` 将是代码块而非保存。建议 Shell HardwareKeyboard 全局处理 keyS，或显式覆盖 quill 默认 shortcuts。
4. **进入沉浸不显式先保存**：设计「进入：保存 → 隐藏」，实现仅切换 `_focusMode`（shell.dart:77-80）；防抖计时器继续运行 + journal 兜底，风险极低，可在 `onToggleFocusMode` 中顺手 flush。
5. **「点击空白收起工具栏」覆盖不完整**：编辑器内点击空白 → 选区折叠 → 收起（editor.dart:155-161）；点击编辑器外空白（如侧边栏）选区保持、工具栏不收起。建议编辑器失焦时同时收起。
6. **动效未实现**（style.md §7）：工具栏 100ms 淡入、沉浸进出 200ms、已保存 150ms 淡入/300ms 淡出、占位斜体（style.md §9 空态斜体 text-tertiary，quill placeholder 未定制斜体）——纯视觉打磨，非功能 contract。
7. **测试覆盖缺口**：Android 热区点按/下滑退出与 PopScope（平台门控，macOS 测试环境不可达）；沉浸进出光标/滚动保持（现有沉浸测试只断言 chrome 显隐）；Windows Ctrl+S 路径（受非阻塞 3 影响）。
8. **既有测试 flake**：全量跑 1/4 次出现 sidebar「文档上移/下移」失败（隔离与后续 3 次全量均通过）——`runAsync` + 80ms settle 时序敏感（sidebar_test.dart:20-23），非本提交代码，建议后续加固。
9. **状态栏点击今日进度 → 打开设置页**（ui-editor.md Interactions）未在本提交实现——属 set-004 排期（并发工作树已开始接线 `onOpenSettings`），非 edit-003 范围。
