## 非阻塞发现（建议追加 backlog）

1. **`progress` 恒 null**：update.dart:96 定义后零赋值，UI「下载中 n%」分支（settings_view.dart:520-528）恒不显示；`download` 为一次性 `http.get` 无流式进度。转圈可满足「更新中显示进度」最低要求。
2. **`UpdateStatus.available` 死枚举成员**（update.dart:68）——B3 同源，修 B3 时启用或删除。
3. **minDbSchema 语义偏差**：update.md §4 末行「更新清单 minDbSchema > 本地 → 更新安装后首次启动自动迁移」，实现为直接拒绝安装（「请先升级中间版本」）——方向更保守（不会装出打不开的新库），建议任务文档对齐或注明。
4. **macOS codesign 校验缺失**（update.md §3.4「同时校验 codesign 状态」）：当前仅「右键打开」文案提示；自用未签名 App 场景可接受，后续版本补。
5. **下载失败重试**：无自动重试、无 HTTP 失败注入测试；`updateUrl` 为空串时点「检查更新」报底层异常文案（`Uri.parse('')` 请求异常经 catch 转「检查更新失败: …」），建议空 URL 给友好提示。
6. **`_platformKey` Linux 回退 'macos'**（update.dart:168-173）：当前仅三平台目标，Linux 会尝试下载 macos 包，建议明确拒绝。
7. **`settings_controller.dart:33-35` 新增公开 `Db get db`**：update.url 持久化需要，但把底层库暴露给 UI 层，本任务范围内可接受。
