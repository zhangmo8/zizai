## 非阻塞发现（建议追加 backlog）

1. **选中项底色用 M3 派生色而非 `surface-hover` token**（style.md §9）：`_DocumentTile` 选中底为 `scheme.surfaceContainerHighest`（sidebar.dart:374），而规范要求 `surface-hover`（浅 `#F0EEEA`）。根因是 shell-001 backlog 项 1 未落地——`AppTheme._build` 的 `copyWith` 仍未接线 surface/surface-hover/text-tertiary/success（app.dart:85-91），侧边栏面板底也因此是 `bg` 而非 `surface`。视觉形态（2px accent 竖条 + 浅灰底 + accent 字）已达标，仅色值偏差；建议在主题层补 `surfaceContainerHighest: surfaceHover`（或等效接线）后，侧边栏一行 token 调用即合规。
2. **行操作未按「平时隐藏，hover 浮现」呈现**（style.md §9「低打扰 chrome」）：`⋮` 菜单与「+ 新建章节」按钮常驻显示（sidebar.dart:331-338,487-489,512-526），未做 hover 门控。功能完整（菜单可用），纯视觉/打扰度问题；Flutter 桌面 hover 态可用 `MouseRegion` + InkWell hover 实现，建议打磨期跟进。
3. **测试覆盖缺口**：① `Ctrl/Cmd+B` 无 widget 测试（桌面快捷键依赖 `HardwareKeyboard`，widget 测试驱动成本高）；② 笔记本上移/下移与笔记本删除级联（FK cascade）无 UI 层测试（db 层 swap 逻辑已由 core 测试覆盖）。不影响验收，建议补测。
