# 设置页布局

Status: Draft（v3：双栏分类导航）

## Overall Structure

桌面为双栏模态对话框（宽 840px、高 620px）；Android 为全屏页面，在顶部提供可横向滚动的分类导航。设置均为即时保存，关闭页面不需要二次确认。

```text
┌────────────────────────────────────────────────────────────────────┐
│ 设置                                                            × │
├───────────────────┬────────────────────────────────────────────────┤
│ 偏好设置           │ 外观                                           │
│                   │ 自定义阅读与编辑体验                            │
│ ▣ 外观             │                                                │
│ ☁ 备份             │ 界面                                           │
│ □ 数据             │ 主题                    [跟随系统 ▾]          │
│ ───────────────── │ 字体                    [系统默认 ▾]          │
│ ⓘ 关于             │                                                │
│                   │ 编辑器                                         │
│                   │ 字号                  [──●────] 18             │
│                   │ 行距                  [──●────] 1.8            │
│                   │ 预览：这是一段用于调整阅读体验的文字。          │
│                   │                                                │
│ ───────────────── │                                                │
│ ↻ 恢复默认         │                                                │
└───────────────────┴────────────────────────────────────────────────┘
```

> 说明：「写作」分类已迁移到**「这本书的设置」**（见下）。原写作分类下的
> 「写作目标」「段落缩进」按书配置；「字数统计（标点计入）」「焦点暗淡」
> 并入「外观 → 字数统计 / 焦点暗淡」分组。

## Page-level Layout

| 平台 | 导航 | 内容 | 操作 |
|---|---|---|---|
| 桌面（可用宽度 ≥ 720px） | 左栏宽 204px；当前项高亮；「关于」前有分隔线 | 右栏可滚动，内容最大宽 580px | 「恢复默认」固定在左栏底部；右上角 `×` 关闭 |
| Android / 窄屏 | 标题下方横向滚动分类标签 | 单栏可滚动内容 | 底部显示「恢复默认」和「关闭」；右上角 `×` 也可关闭 |

分类仅在功能已接线时显示：`备份` 需要 `BackupManager`；`关于` 常驻（版本信息与软件更新组随 `UpdateChecker` 接线显隐，帮助组始终可用）。备份入口默认打开「备份」；状态栏今日进度点击 → 打开「这本书的设置」并聚焦每日目标字数。

## 「这本书的设置」（书内设置对话框）

单书工作区侧边栏顶栏 `⚙` 打开，针对当前打开的这本书：

| 分组 | 项 | 说明 |
|---|---|---|
| 写作目标 | 启用今日目标 / 每日目标字数 | 每本书独立计算今日进度（原全局「写作」分类迁移） |
| 段落缩进 | 行首自动缩进 | 中文排版首行空两格（原全局「写作」分类迁移） |
| 分卷 | 启用分卷 / 每卷章数 | 开启后按每卷章数在目录里视觉分组为「第 N 卷」（不动库） |

持久化键：`notebookGoal.<id>.enabled/.words`、`paragraphIndent.<id>`、
`volume.<id>.enabled/.chapters`（settings 表）。

## Region Layout

| 分类 | 设置项 | 说明 |
|---|---|---|
| 外观 / 界面 | 主题 | `跟随系统 / 浅色 / 深色` 下拉，即改即存 |
| 外观 / 界面 | 字体 | 系统可用字体候选 + 「系统默认」 |
| 外观 / 编辑器 | 字号 | Slider 12–28，步进 1，实时预览 |
| 外观 / 编辑器 | 行距 | Slider 1.2–2.4，步进 0.1，实时预览 |
| 写作 | 笔记本 / 启用今日目标 / 每日目标字数 | 选择笔记本后独立开关并设置 100–50000；关闭后隐藏该本进度 |
| 写作 | 行首自动缩进 | 针对「写作目标」选中的笔记本独立开关（settings 键 `paragraphIndent.<id>`，默认关）；开启后新段落行首自动空两个全角空格（中文排版） |
| 写作 | 标点计入字数 | 开关，即改即存，影响字数统计与今日增量 |
| 写作 | 暗淡非当前行 | 开关（settings 键 `focusDim`，默认关）；开启后编辑器仅高亮光标所在段落，其余蒙页面底色，见 ui-editor.md §焦点暗淡；顶栏 icon 同步此状态。**同时联动打字机滚动**：光标所在行平滑滚动到视口中部（120ms easeOut），无独立开关 |
| 备份 | Account ID / Bucket / Access Key / Secret Key | Cloudflare R2 备份凭据；Secret Key 掩码显示，仅保存在本机 settings 表 |
| 备份 | 上次备份 / 立即备份 | 只读最近状态；按钮手动触发备份，进行中显示进度态 |
| 数据 / 本地数据 | 数据库路径 | 只读展示；「打开目录」在文件管理器中定位（Android 隐藏） |
| 数据 / 本地数据 | 诊断日志 | 本地滚动记录启动、版本升级、更新与未处理异常；桌面展示路径并可打开日志目录，Android 可直接分享日志文件 |
| 数据 / 导出 | 当前文档 | 桌面：系统保存对话框（`.txt`）；Android：系统分享纯文本 |
| 数据 / 导出 | 整本书 | 「导出全书…」打开选项对话框：范围（全书/单笔记本）、格式（TXT 单文件 / Markdown 单文件 / 每章一个 Markdown 文件，后者仅桌面）、章节自动编号（「第 X 章」，全书连续，已带编号不重复加）、段首缩进与段间空行（仅 TXT）。桌面走保存对话框/选目录，Android 分享文本；完成 toast「已导出 N 章」。无章节时该行显示「还没有章节」 |
| 关于 / 版本信息 | App 版本 / 数据库版本 | 只读（pubspec version / `PRAGMA user_version`）；该组随 `UpdateChecker` 接线显隐 |
| 关于 / 软件更新 | 检查更新 | 不暴露更新地址（内部默认配置）；拉取 R2 `update.json`；有新版 → 确认下载、校验、安装；该组随 `UpdateChecker` 接线显隐 |
| 关于 / 帮助 | 快捷键说明 | 「查看」按钮打开快捷键面板：全局 / 编辑 / Markdown 快捷语法分组展示，macOS 显示 ⌘、其余 Ctrl |

每一行的左侧为项目名与可选的辅助说明，右侧为控制项；分组内行间使用 hairline 分隔，不再使用堆叠卡片。

## Interactions

| 输入 | 范围 | 行为 |
|---|---|---|
| 左栏条目 / 顶部标签 | 设置页 | 切换分类；切换前收起当前输入焦点 |
| 字号/行距 Slider | 外观 | 实时作用于编辑器（内嵌一行示例文本预览） |
| 笔记本目标 | 写作 | 每个笔记本独立开关/保存；字数 100–50000，非法输入不改变原值 |
| R2 凭据 | 备份 | 输入保存；校验失败显示错误，密钥不会导出或同步推送 |
| 立即备份 | 备份 | 手动触发；完成后刷新「上次备份」 |
| 导出当前文档 | 数据 | 导出当前文档纯文本；失败显示错误（不可写路径） |
| 导出全书 | 数据 | 打开导出对话框选项详见上表；用户取消保存对话框时不关闭选项对话框、不提示 |
| 检查更新 | 关于 | 拉取清单比较；有新版 → 确认下载 → sha256 校验 → 安装 |
| 打开目录 | 数据 | 定位 db 所在目录（桌面） |
| 恢复默认 | 全局 | 先显示确认框；确认后重置外观与每日目标，不删除文档或备份 |
| `×` / Esc | 全局 | 关闭并保留所有已即时保存的改动 |

## State Variants

- **导出失败**：错误提示条（路径不可写/当前无文档）。
- **当前无文档**：导出按钮禁用，附说明「先打开一个文档」。
- **备份失败**：备份区显示最近错误 + 重试按钮；进行中按钮转圈。
- **更新可用**：「检查更新」按钮由次级升为 accent 主按钮，label 携带新版本号；下载中按钮内 spinner + 旁侧 4px 细进度条与百分比。
- **窄屏**：导航不压缩为双栏；改为可横向滚动的顶部标签，底部保留关闭入口。

## Component Tree

```text
SettingsView
├─ Header（title / CloseButton）
├─ Desktop: SettingsNav
│  ├─ CategoryItem（Appearance / Writing / Backup? / Data / About?）
│  └─ ResetDefaultsButton
├─ Mobile: HorizontalCategoryNav
├─ SettingsPage（current category）
│  ├─ SettingsGroup
│  │  └─ SettingsRow（label / description? / control）
│  └─ …
└─ Mobile: Footer（ResetDefaults / Close）
```

## Page Entry Points

- 编辑器顶栏设置按钮。
- 状态栏今日进度点击（定位到「每日目标字数」并打开「写作」）。
- 状态栏备份入口（定位到「备份」）。
- Android：Drawer 底部入口。
