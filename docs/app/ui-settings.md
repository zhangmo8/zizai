# 设置页布局

Status: Draft（v2：新增导出）

## Overall Structure

桌面为对话框（模态，宽 480px），Android 为全屏页面。

```text
┌─────────────────────────────┐
│ 设置                      × │
├─────────────────────────────┤
│ 外观                         │
│  主题        [跟随系统 ▾]     │
│  字体        [系统默认 ▾]     │
│  字号        [──●────] 18    │
│  行距        [──●────] 1.8   │
│  ───────────────────────    │
│ 写作                         │
│  每日目标字数  [    2000   ] │
│  ───────────────────────    │
│ 同步                         │
│  云同步        [关闭 ▾]      │
│  同步令牌      [•••••••• ]   │
│  上次同步      2 分钟前       │
│              [立即同步]      │
│  ───────────────────────    │
│ 数据                         │
│  数据库路径  …/zi-zai.db  [打开目录] │
│  导出当前文档              [导出] │
│  ───────────────────────    │
│ 关于                         │

│  数据库版本    schema v1     │
│              [检查更新]      │
│                              │

└─────────────────────────────┘
```

## Region Layout

| 区块 | 设置项 | 说明 |
|---|---|---|
| 外观 | 主题 | `跟随系统 / 浅色 / 深色` 下拉，即改即存 |
| 外观 | 字体 | 系统可用字体列表 + 「系统默认」 |
| 外观 | 字号 | Slider 12–28，步进 1，实时预览 |
| 外观 | 行距 | Slider 1.2–2.4，步进 0.1，实时预览 |
| 写作 | 每日目标字数 | 数字输入框（100–50000），状态栏进度即时刷新 |
| 同步 | 云同步开关 | 关闭/开启（默认关闭）；开启后显示令牌输入与状态 |
| 同步 | 同步令牌 | 文本输入（自配 CF Worker token），掩码显示；token 仅存本地 settings 表，绝不随同步推送 |
| 同步 | 上次同步 + 立即同步 | 只读时间显示；按钮手动触发同步，同步中显示进度态 |
| 数据 | 数据库路径 | 只读展示；「打开目录」在文件管理器中定位（Android 隐藏） |
| 数据 | 导出当前文档 | 桌面：系统保存对话框（.txt）；Android：系统分享（分享为文本） |
| 关于 | App 版本 | 只读（pubspec version） |
| 关于 | 数据库版本 | 只读（`PRAGMA user_version` 当前值） |
| 关于 | 检查更新 | 拉取 R2 `update.json`；有新版 → 提示 + 下载安装（sha256 校验） |

## Interactions

| 输入 | 范围 | 行为 |
|---|---|---|
| 字号/行距 Slider | 设置页 | 实时作用于编辑器（内嵌一行示例文本预览） |
| 云同步开关 | 设置页 | 关闭 → 停用同步（不删本地数据）；开启 → 校验令牌后拉取 |
| 同步令牌 | 设置页 | 输入保存；令牌校验失败显示错误 |
| 立即同步 | 设置页 | 手动触发 push+pull；完成后刷新「上次同步」 |
| 导出当前文档 | 设置页 | 导出当前文档纯文本；失败显示错误（不可写路径） |
| 检查更新 | 设置页 | 拉取清单比较；有新版 → 确认下载 → sha256 校验 → 安装 |
| 打开目录 | 设置页 | 定位 db 所在目录（桌面） |
| 恢复默认 | 设置页 | 重置为默认值（不删除任何文档） |
| `×` / Esc | 全局 | 关闭并保存已改项 |

## State Variants

- **导出失败**：错误提示条（路径不可写/当前无文档）。
- **当前无文档**：导出按钮禁用，附说明「先打开一个文档」。
- **同步失败**：同步区显示最近错误 + 重试按钮；同步中按钮转圈。
- **更新可用**：「检查更新」按钮变为 accent 色 + 徽标；更新中显示进度。

## Component Tree

```text
SettingsView
├─ Section「外观」（ThemePicker / FontPicker / FontSizeSlider / LineHeightSlider）
├─ Section「写作」（DailyGoalField）
├─ Section「同步」（SyncToggle / SyncTokenField / LastSyncRow / SyncNowButton）
├─ Section「数据」（DbPathRow / OpenDirButton / ExportButton）
├─ Section「关于」（AppVersionRow / DbVersionRow / CheckUpdateButton）
└─ ActionsRow（ResetDefaults / Done）
```

## Page Entry Points

- 编辑器顶栏设置按钮。
- 状态栏今日进度点击（定位到「每日目标字数」并聚焦）。
- Android：Drawer 底部入口。
