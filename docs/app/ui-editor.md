# 编辑器布局与交互

Status: Draft（v4：常驻格式工具栏 + 选区浮动工具栏）

## Overall Structure

```text
┌────────────────────────────────────────────────┐
│ 01-开端                    [沉浸] [设置]         │  ← 顶栏（文档名 + 动作）
├────────────────────────────────────────────────┤
│ ↶ ↷ │ H1 H2 H3 │ B I U S 🔗 │ ⋮列表 │ ❝ <> 🧹  │  ← 常驻格式工具栏（始终可见）
├────────────────────────────────────────────────┤
│                                                │
│              内容区（最大行宽 720px，居中）       │
│    ▍光标所在行                                  │
│    加粗/斜体/列表/引用 所见即所得                │
│                                                │
├────────────────────────────────────────────────┤
│ 今日 420/2000 █████░░ 20%       本文 6,238 字    │  ← 状态栏
└────────────────────────────────────────────────┘

常驻格式工具栏在顶栏下方始终可见（沉浸模式改为精简悬浮工具栏，见 §FocusMode 细节），不随选区出现/消失；光标移动时实时高亮所在位置的格式。选中文本时，另由编辑器选区 overlay 在选区上方浮现同款上下文工具栏（Notion 式，就近操作）；靠近屏幕边缘时由框架翻转到选区下方：

```text
                 ┌──────────────┐
                 │ H1 B I U ▾ ▾ │  ← 锚定于实际选区
                 └──────────────┘
       ─────── 被选中的文字 ───────
```

沉浸模式（FocusMode）隐藏顶栏与状态栏，内容区全屏，顶部常驻一条精简悬浮工具栏（进入方式和退出方式见 §FocusMode 细节）。

## Region Layout

| 区域 | 内容 |
|---|---|
| 顶栏 | 最左侧「侧边栏」切换按钮（menu icon，active 态跟随；桌面 tooltip 带 `Ctrl/Cmd+B` 提示，Android 点击打开 Drawer）；面包屑「笔记本 / 文档名」（长名省略）；点击文档名后原地编辑，`Enter`/失焦保存、`Esc` 取消；右侧依次为查找、版本历史、大纲、沉浸按钮（icon + tooltip） |
| 内容区 | flutter_quill 编辑器（`QuillEditor`），行宽约束 760px，居中 |
| 常驻格式工具栏 | 顶栏下方始终可见：撤销/重做、标题 H1–H3、加粗/斜体/下划线/删除线、链接、无序/有序列表、待办清单、引用、行内代码、代码块、清除格式；监听控制器实时高亮光标处格式；沉浸模式改为精简悬浮工具栏（见 §FocusMode 细节） |
| 上下文工具栏 | 选中文本时在实际选区上方浮现同款格式按钮（就近操作）；由 `QuillEditorConfig.contextMenuBuilder` 交给 Flutter/Quill 选区锚点定位 |
| 斜杠菜单 | 输入 `/` 在光标下方浮现块命令菜单（触底翻转到上方）：正文、H1–H3、无序/有序列表、待办清单、引用、代码块；继续输入过滤（中文/英文/拼音关键词），`↑↓` 导航、`Enter` 应用、`Esc`/点击外部关闭 |
| 状态栏 | 当前笔记本今日新增/目标 + 进度条 + 本文总字数；目标关闭时只显示本文 |

工具栏内容在窄屏保持单行横向滚动，不能溢出屏幕；工具栏仅提供格式化操作，不替换复制、粘贴等系统选区菜单。

## Interactions

| 输入 | 范围 | 行为 |
|---|---|---|
| 顶栏侧边栏按钮 | 全局（非沉浸） | 桌面：切换侧边栏显隐（同 `Ctrl/Cmd+B`）；Android：打开 Drawer |
| 输入/格式化 | 内容区 | 即时渲染所见即所得；更新字数；启动 1s 防抖自动保存 |
| 失焦 | 内容区 | 立即保存 |
| 切换文档/退出 | 全局 | 保存当前文档后执行 |
| `Ctrl/Cmd + S` | 桌面 | 立即保存，状态栏闪「已保存」1s |
| `Ctrl/Cmd + I / U` | 桌面 | 斜体/下划线（编辑器内置） |
| 加粗 | 桌面 | 工具栏/上下文工具栏按钮（`Ctrl/Cmd + B` 被全局占用为侧边栏切换，见 ui-shell.md） |
| 行首触发词 + 空格 | 内容区 | Markdown 快捷块转换：`#`/`##`/`###` → H1–H3、`-`/`*` → 无序列表、`1.` → 有序列表、`>` → 引用、`[]`/`[x]` → 待办、`` ``` `` → 代码块（触发词被消费，不入正文） |
| 行内 markdown | 内容区 | `**加粗**`、`*斜体*`、`` `行内代码` ``、`~~删除线~~`（flutter_quill 标准字符事件） |
| 输入 `/` | 内容区 | 打开斜杠命令菜单（锚定光标）；选择后删除 `/query` 并转换当前行块格式 |
| 选中文本 | 内容区 | 在选区锚点附近浮现上下文工具栏；点击空白或 `Esc` 收起 |
| 常驻工具栏按钮 | 全局（非沉浸）；沉浸模式的精简悬浮工具栏同样适用 | 光标处/选区应用对应格式；撤销/重做随历史可用性置灰；「清除格式」移除行内 + 块级样式回到正文 |
| 工具栏「链接」 | 选区 | 弹小对话框输入 URL（无协议自动补 `https://`）；已有链接可移除 |
| `Ctrl/Cmd + F` | 桌面 | 打开查找/替换条（见 §查找与替换）；`Esc` 关闭 |
| `Ctrl/Cmd + Shift + F` | 桌面 | 进入沉浸模式 |
| `Esc` | 沉浸模式 | 退出沉浸模式 |
| 状态栏点击今日进度 | 全局 | 打开设置页定位到「每日目标字数」 |

自动保存失败：状态栏「保存失败」红色提示 + 重试；文本缓冲区保留在内存，直至保存成功。

性能约束：实时字数经 `LibraryController.liveWords`（`ValueNotifier`）下发，仅状态栏/沉浸字数条局部重建；逐键输入不触发 Shell 全树 rebuild。

## Word Count 规则

- 输入：`QuillController.document.toPlainText()`。
- 中文/日文/韩文按 1 字符 = 1 字；连续英文/数字按词计 1 字；空白与标点不计。
- 纯函数 `wordCount(String) → int`，编辑器与状态栏共用。

## FocusMode 细节

| 项 | 行为 |
|---|---|
| 进入 | 保存 → 隐藏顶栏/状态栏/侧边栏 → 全屏编辑器 + 精简悬浮工具栏；顶部短暂浮现「沉浸模式 · 按 Esc 退出」提示（≈2.6s 后自动淡出） |
| 退出（桌面） | `Esc`；或点击悬浮工具栏最前的「退出沉浸」按钮（accent 色高亮，常驻可见）。退出后焦点自动回到编辑器 |
| 退出（Android） | **主路径：系统返回手势/返回键**（PopScope 拦截 → 退出沉浸，不退出 App）；**兜底：顶部 48px 热区**——点按弹出「退出 + 当前字数」条（触摸设备无 hover，需显式触碰目标），向下滑热区直接退出 |
| 热区与滚动 | 热区是固定于屏幕顶部的独立 overlay 层，不拦截编辑区滚动；编辑器顶部留足 padding，不遮挡首行 |
| 状态保持 | 进出不打断光标位置与滚动（退出后焦点回编辑器中，见前文） |
| 格式化 | 非沉浸时常驻工具栏始终可用；选中文本 → 另有选区锚定工具栏浮现；沉浸模式显示精简悬浮工具栏（前置「退出沉浸」按钮 + 标题 H1–H3、加粗/斜体/下划线、无序/有序/待办列表） |
| 字数可见性 | Android 沉浸时字数隐藏；点按顶部热区弹出的条内显示「本文 x 字 · 今日 x/目标」 |
| 打字机滚动 | V1 不做（backlog） |

## 焦点暗淡（Focus Dim）

写作辅助：光标所在段落保持全亮，其余段落蒙一层页面底色（≈60% 不透明度），视线聚焦当前段落。与沉浸模式相互独立、可叠加（沉浸 + 暗淡 = 纯码字焦点流）。

| 项 | 行为 |
|---|---|
| 开关 | EditorHeader icon（contrast 图标，active 态高亮）+ 设置页「写作」区「暗淡非当前行」开关；settings 表 `focusDim`，默认关 |
| 亮区 | 光标（选区 base）所在**段落块**；跨段落选区时为 base..extent 覆盖的全部段落（选中内容保持可读） |
| 蒙层 | 编辑器内容宽度内、亮区上方与下方各一块页面底色（scaffoldBackground @ 60%）矩形；IgnorePointer overlay，不拦截输入/滚动/选区 |
| 刷新 | 选区/文档变更、滚动时逐帧跟随（订阅 controller + scrollController 重绘） |
| 空态 | 无文档或选区无效（如编辑器未挂载）时不绘制蒙层 |
| 兼容 | 沉浸模式照常生效；查找条/上下文工具栏/悬浮工具栏绘制于蒙层之上，不受影响 |

## 大纲面板（Outline）

单文档大纲：从 Delta 的 `header: 1|2|3` 行提取「标题文本 + 层级 + 偏移」，编辑防抖管道增量刷新。

| 项 | 行为 |
|---|---|
| 形态 | 编辑区右侧可折叠面板（宽 200–240px）；H1–H3 缩进呈现，行样式按 style.md text-secondary，当前标题 accent 高亮 |
| 展开/收起 | EditorHeader 最右侧 icon 切换（大纲 icon，展开态 active）；状态记忆（settings 表），窄窗（<960px）强制收起 |
| 收起时悬浮 | 鼠标移入窗口右缘热区（8px）→ 大纲以 overlay 浮层滑出（不挤压编辑区）；鼠标离开浮层即收起。热区是固定 overlay，不拦截编辑区滚动 |
| 沉浸模式 | 自动收起（不显示常驻面板），右缘悬浮热区保持可用（与顶缘退出条同一 hover 模式）；退出沉浸恢复原展开状态 |
| 点击跳转 | 光标移至该标题行首并滚动到视口上 1/3 处；跳转不打断未保存缓冲 |
| 跟随高亮 | 滚动/光标移动时，视口内最上方标题在面板中高亮并保持可见 |
| 空态 | 文档无标题行 → 面板显示「使用 H1–H3 标题，这里会生成大纲」引导文案 |
| Android | 无 hover：仅 icon 切换展开/收起，收起即不可见；沉浸模式不提供大纲 |
| 范围 | 仅当前文档（跨文档/整本书层级视图另行设计） |

## 查找与替换（Find & Replace）

范围：仅当前文档。入口：顶栏搜索 icon 或 `Ctrl/Cmd + F`；查找条为编辑区右上角浮层（GlassSurface，圆角 6px），不挤压编辑区。跨全书搜索见 ui-sidebar.md §全书搜索——命中点击后由编辑器完成跳转定位（切换文档 → 选中命中词 → 滚动到视口上 1/3 处）。

| 项 | 行为 |
|---|---|
| 查找 | 输入即匹配（大小写不敏感、不重叠）；计数显示「当前/总数」，无匹配显示「无结果」 |
| 初始查询 | 打开时若有单行选区（≤64 字符）自动带入 |
| 定位 | 当前匹配以选区高亮，滚动到视口上 1/3 处；`Enter`/`↓` 下一个、`Shift+Enter`/`↑` 上一个，循环回绕 |
| 替换 | 折叠行展开后可见：「替换」替换当前匹配并跳到下一个；「全部替换」从后往前一次性替换并 toast 数量 |
| 关闭 | `Esc` 或关闭按钮；焦点交还编辑器 |
| 编辑联动 | 文档编辑时匹配实时重算（只刷新计数，不打断输入）；切换文档自动关闭 |

## 版本历史（Snapshot History）

单文档本地版本留底：轻量 JSON 文件存于库目录旁 `snapshots/<documentId>/`，与云备份的全量快照（sync.md）无关，不参与同步。入口：顶栏「版本历史」icon（未接线时隐藏）。

| 项 | 行为 |
|---|---|
| 自动留底 | 保存链路写库前判定（core/snapshot_history.dart `SnapshotPolicy`）：① 文档首次有内容保存 → 基线；② 单次保存字数骤降（≥200 字，或 ≥50 字且 ≥ 旧字数 20%）→ 留住删除前内容；③ 距上次快照 ≥10 分钟 → 周期留底。空文档不留底；快照失败只记日志，不阻塞保存 |
| 上限 | 每文档保留 50 份，超出按时间淘汰最旧 |
| 对话框 | 打开前先 flush 保存（列表与所见一致）。左列时间+字数列表（今天显示「今天 HH:mm」），右侧纯文本预览；顶部「留存当前版本」手动留底 |
| 回滚 | 确认弹层 →（当前内容先自动留底）→ 写库 → 编辑器就地重载（同文档 id 必须显式重载，防止旧缓冲经自动保存覆盖回滚结果）→ toast。只回滚正文，标题不变；不倒扣今日字数 |
| 删除 | 预览底部「删除」（danger 确认）仅删单份留底 |
| 空态 | 「还没有历史版本」+ 自动留底说明 |

## State Variants

- **空文档**：内容区首行占位「输入 / 唤起命令，或直接开始写…」（Quill 原生占位，输入后消失）。
- **未选择文档**：内容区居中引导「在左侧选择或新建一篇文档，开始写作」（编辑器保持挂载）。
- **保存失败**：状态栏错误条 + 重试。
- **恢复**：启动时内存缓冲与库中内容不一致（崩溃场景）→「检测到未保存内容，恢复？」确认条。
- **db 损坏**：打开失败 → 提示 + 尝试 `.bak` 恢复，恢复失败则引导导出 db 文件。

## Component Tree

```text
EditorView
├─ EditorHeader（SidebarToggle / breadcrumb / EditableTitle / Find・History・Outline・Focus icons）
├─ FormatToolbar（常驻格式工具栏：ListenableBuilder ← QuillController）
├─ ContentArea
│  └─ QuillEditor
│     ├─ SelectionOverlay（contextMenuBuilder → FloatingFormatToolbar）
│     └─ spaceShortcutEvents / characterShortcutEvents（markdown 快捷）
├─ SlashMenu（OverlayEntry：锚定光标的块命令菜单）
├─ StatusBar
│  ├─ TodayProgress（今日增量 / 目标 + LinearProgressIndicator）
│  └─ DocWordCount（ValueListenableBuilder ← liveWords）
└─ FocusView ──包装──► EditorView（隐藏 chrome）
```
