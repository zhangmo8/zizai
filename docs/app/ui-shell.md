# 主界面壳（Shell）布局

Status: Draft

## Design Principles

- 编辑器是主角，chrome 让位：侧边栏默认收起/可收起，无顶部工具栏。
- 桌面与 Android 共用同一套区域，宽度自适应切换形态。
- **两层结构**：笔记本管理层（LibraryHome，应用入口）→ 单书工作区（Shell）。
  进入/退出工作区是声明式的：`LibraryController.currentNotebook` 非空 → Shell；
  否则 → LibraryHome。点书 openNotebook，返回（侧边栏顶栏 ←）closeNotebook。

## Overall Structure

### 笔记本管理层（LibraryHome）

```text
┌────────────────────────────────────────────────┐
│ 笔记本              [grid|list] [+] [⚙ 设置]    │  ← 顶栏：标题 + 视图切换 + 新建 + 全局设置
├────────────────────────────────────────────────┤
│  ┌──────────┐ ┌──────────┐ ┌──────────┐       │
│  │ 我的小说   │ │ 随笔集    │ │ …        │ 卡片网格 │
│  │ 12 章 · 3万│ │ 0 章 · 0字│ │          │（无封面）│
│  └──────────┘ └──────────┘ └──────────┘       │
└────────────────────────────────────────────────┘
```

- 卡片/行：书名 + 章节数 + 总字数；点书进入单书工作区。
- 右上角：grid/list 视图切换、新建笔记本、全局设置。
- 笔记本 CRUD（新建/改名/删除）在此层完成。

### 单书工作区（Shell）

```text
┌────────────────────────────────────────────────────────┐
│ ┌─────────┐  ┌──────────────────────────────────────┐  │
│ │ 侧边栏   │  │                                      │  │
│ │ 260px   │  │  编辑器区（含滚动）                     │  │
│ │ 单书树   │  │                                      │  │
│ │         │  └──────────────────────────────────────┘  │
│ │         │  ┌──────────────────────────────────────┐  │
│ │         │  │ 状态栏（今日 x/目标 ▎本文 x 字）        │  │
│ └─────────┘  └──────────────────────────────────────┘  │
└────────────────────────────────────────────────────────┘
```

## Page-Level Layout

| 区域 | 尺寸 | 内容 |
|---|---|---|
| 侧边栏 | 桌面 260px 固定；Android 隐藏为 Drawer（340px 滑出） | 单书文档树，见 ui-sidebar.md |
| 编辑器区 | 自适应填充 | 编辑页面，见 ui-editor.md |
| 状态栏 | 高度 32px，通栏 | 今日增量/目标 + 同步状态 + 当前文档字数 |

条件区域：
- 沉浸模式：侧边栏与状态栏整块隐藏（见 ui-editor.md FocusMode）。
- 无当前笔记本：应用门控展示笔记本管理层，无工作区。

## Interactions

| 输入 | 范围 | 行为 |
|---|---|---|
| `Ctrl/Cmd + B` | 全局（桌面） | 切换侧边栏显隐（EditorHeader 左侧 menu 按钮同样可切换，见 ui-editor.md） |
| `Ctrl/Cmd + P` | 全局（桌面） | 打开全书搜索（ui-sidebar.md §全书搜索）；沉浸模式下吞掉不响应 |
| Drawer 边缘滑动 | Android | 打开/关闭侧边栏 |
| 遮罩点击 | Android Drawer | 关闭抽屉 |
| 系统返回键 | Android | 分层拦截（Shell PopScope）：沉浸模式 → 退出沉浸；Drawer 开着 → 只关 Drawer；否则 → 关当前笔记本回书架。**不直接退出 App**（书架页返回才退出） |
| 同步状态点 | 全局 | 点击进入设置页同步区；同步失败时悬停显示最近错误 |
| 启动 | 全局 | 恢复上次文档；无记录则显示空态（ui-sidebar.md） |

同步状态显示规则：`● 已同步`（accent）/ `⟳ 同步中`（text-secondary）/ `⚠ 失败 n 次`（danger）；已配置但本次会话尚未备份 → `☁ 未备份`（text-secondary）；云同步关闭时不显示该区块。

## State Variants

- **启动加载**：目录树加载中 → 侧边栏显示骨架条；编辑器区显示占位「载入中…」。
- **空库**：无任何笔记本 → 侧边栏显示「新建笔记本」引导按钮；编辑器区显示空态插画文案。
- **存储错误**（目录不可读/写失败）：状态栏左侧出现红色错误条，点击重试；阻止新建/保存操作。

## Component Tree

```text
Shell
├─ Sidebar (desktop) / Drawer (Android)
│   └─ DocumentTree
├─ EditorArea
│   └─ EditorView
└─ StatusBar
    ├─ TodayProgress
    ├─ SyncIndicator
    └─ DocWordCount
```

## Page Entry Points

- 桌面：`main.dart` → `Shell`（全窗）。
- Android：`main.dart` → `Shell`（竖屏优先）。
- 沉浸模式与设置从 Shell 内的入口进入（快捷键/状态栏按钮）。
