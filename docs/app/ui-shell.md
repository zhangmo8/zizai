# 主界面壳（Shell）布局

Status: Draft

## Design Principles

- 编辑器是主角，chrome 让位：侧边栏默认收起/可收起，无顶部工具栏。
- 桌面与 Android 共用同一套区域，宽度自适应切换形态。

## Overall Structure

```text
┌────────────────────────────────────────────────────────┐
│ ┌─────────┐  ┌──────────────────────────────────────┐  │
│ │ 侧边栏   │  │                                      │  │
│ │ 240px   │  │  编辑器区（含滚动）                     │  │
│ │         │  │                                      │  │
│ │         │  └──────────────────────────────────────┘  │
│ │         │  ┌──────────────────────────────────────┐  │
│ │         │  │ 状态栏（今日 x/目标 ▎本文 x 字）        │  │
│ └─────────┘  └──────────────────────────────────────┘  │
└────────────────────────────────────────────────────────┘
```

## Page-Level Layout

| 区域 | 尺寸 | 内容 |
|---|---|---|
| 侧边栏 | 桌面 240px 固定；Android 隐藏为 Drawer（360px 滑出） | 文档树，见 ui-sidebar.md |
| 编辑器区 | 自适应填充 | 编辑页面，见 ui-editor.md |
| 状态栏 | 高度 32px，通栏 | 今日增量/目标 + 同步状态 + 当前文档字数 |

条件区域：
- 沉浸模式：侧边栏与状态栏整块隐藏（见 ui-editor.md FocusMode）。

## Region Layout

### 桌面（宽度 ≥ 800px）

```text
┌──────────────────────────────────────────────────────┐
│ 侧边栏  │  编辑器                              │ 滚动条 │
│         │  （内容区最大行宽 720px，水平居中）     │        │
├─────────┴────────────────────────────────────────────┤
│ 今日 420/2000 字  ████████░░░░░░░░░░  20%  │ ● 已同步  │ 本文 6,238 字 │

```

### Android（宽度 < 800px）

```text
┌──────────────────────────────┐
│ 编辑器（全宽，无侧边栏占位）    │
│                              │
├──────────────────────────────┤

Drawer（左滑入，覆盖，宽 360px，含遮罩 0.3 黑）
```

## Interactions

| 输入 | 范围 | 行为 |
|---|---|---|
| `Ctrl/Cmd + B` | 全局（桌面） | 切换侧边栏显隐 |
| Drawer 边缘滑动 | Android | 打开/关闭侧边栏 |
| 遮罩点击 | Android Drawer | 关闭抽屉 |
| 同步状态点 | 全局 | 点击进入设置页同步区；同步失败时悬停显示最近错误 |
| 启动 | 全局 | 恢复上次文档；无记录则显示空态（ui-sidebar.md） |

同步状态显示规则：`● 已同步`（accent）/ `⟳ 同步中`（text-secondary）/ `⚠ 失败 n 次`（danger）；已配置但本次会话尚未备份 → `☁ 未备份`（text-secondary）；云同步关闭时不显示该区块。

## State Variants

- **启动加载**：目录树加载中 → 侧边栏显示骨架条；编辑器区显示占位「载入中…」。
- **空库**：无任何笔记本 → 侧边栏显示「新建笔记本」引导按钮；编辑器区显示空态插画文案。
- **存储错误**（目录不可读/写失败）：状态栏左侧出现红色错误条，点击重试；阻止新建/保存操作。

## Component Tree

```text
Shell
├─ Sidebar (desktop) / Drawer (Android)
│   └─ DocumentTree
├─ EditorArea
│   └─ EditorView
└─ StatusBar
    ├─ TodayProgress
    ├─ SyncIndicator
    └─ DocWordCount
```

## Page Entry Points

- 桌面：`main.dart` → `Shell`（全窗）。
- Android：`main.dart` → `Shell`（竖屏优先）。
- 沉浸模式与设置从 Shell 内的入口进入（快捷键/状态栏按钮）。
