# 侧边栏（文档树）布局

Status: Draft

## Overall Structure

```text
┌─────────────────────┐
│ [Logo]      [🔍] [+笔记] │  ← 顶栏：Logo + 全书搜索 + 新建笔记本按钮
├─────────────────────┤
│ ▾ 我的小说           │  ← 笔记本展开态
│   ▾ 第一卷           │
│     · 01-开端.md   ⋮ │  ← 当前文档高亮，⋮ 打开操作菜单
│     · 02-冲突.md   ⋮ │
│   ▾ 第二卷           │
│     · 03-转折.md   ⋮ │
│ ▸ 随笔集             │  ← 折叠态
│ ▸ 日记               │
├─────────────────────┤
│  空态：               │
│  「新建一本笔记本，    │
│   开始写」            │
└─────────────────────┘
```

层级规则：V1 只支持两层语义——笔记本（文件夹）内为文档；文件夹嵌套仅按文件系统展示，不承诺专门管理交互。

## Region Layout

| 区域 | 内容 |
|---|---|
| 顶栏 | App Logo + 全书搜索 + 新建笔记本（图标按钮，带 tooltip） |
| 树区 | 笔记本列表；展开显示文档；当前文档高亮主题色 |
| 操作菜单 | 每行 `⋮`：上移 / 下移 / 重命名 / 删除（文档与笔记本均支持） |
| 拖拽排序 | 章节行：桌面端前置手柄（平时是章节 icon，hover 切换为拖拽手柄）；触摸端整行长按拖拽；可拖入其它笔记本（跨笔记本移动） |
| 行内编辑 | 名称输入框 + 「保存名称」确认图标 + 「取消编辑」关闭图标；提交中禁用两个操作 |
| 空态 | 无笔记本时的引导区块 |

## Interactions

| 输入 | 范围 | 行为 |
|---|---|---|
| 单击文档 | 树区 | 切换当前文档（先保存旧文档） |
| 单击笔记本行 | 树区 | 展开/折叠 |
| 拖动手柄 / 长按章节行 | 树区 | 章节拖拽排序：桌面端拖前置手柄（平时是章节 icon，hover 变手柄；行体点击不受影响），触摸端长按后拖拽；拖到其它笔记本分区内即跨笔记本移动；落点映射见下方「拖拽排序」 |
| `⋮` → 上移/下移 | 桌面 | 章节或笔记本在所属层级内移动一位（菜单入口与拖拽并存） |
| `⋮` → 重命名 | 桌面 | 行内变成输入框；Enter 或「保存名称」确认；Esc 或「取消编辑」取消 |
| `⋮` → 删除 | 全局 | 弹轻量确认条（「删除《02-冲突.md》？此操作不可恢复」确认/取消）；笔记本删除级联删除文件夹 |
| 顶栏 `+` | 全局 | 弹出「新建笔记本」输入框（默认名「新笔记本」） |
| 顶栏 🔍 / `Ctrl/Cmd + P` | 全局 | 打开全书搜索对话框（见 §全书搜索）；沉浸模式下快捷键不响应 |
| 新建文档 | 全局 | 树底部「+ 新建章节」按钮（或当前笔记本行的 `+`）：点击**直接创建**，标题由 `suggestedChapterTitle` 顺着已有章节自动编号（全部为「第 N 章」式 → 最大序号 +1，沿用原数字风格；空笔记本 → 第 1 章），不进入命名环节；想改名用 ⋮ → 重命名 |
| 空态按钮 | 全局 | 新建笔记本并展开 |

行内编辑与普通树行保持同高；异步写库期间保留编辑行，直到新行或新名称已就绪，避免笔记本和章节在新增、重命名时发生高度闪烁。

删除确认条（非模态）：出现在编辑器区顶部，5s 无操作自动关闭（不删除）。

## State Variants

- **Loading**：骨架行 ×3。
- **Empty**：引导文案 + 主按钮。
- **重命名冲突**：文件名已存在 → 行内输入框显示错误态，不允许确认。
- **非法文件名**（含 `/` 等）：同错误态处理。
- **提交中**：输入框及保存/取消图标禁用，避免重复创建或重命名。

## 拖拽排序（章节）

- 交互：桌面端章节行前置手柄——平时显示章节 icon，鼠标 hover 行时切换为 `⋮⋮` 拖拽手柄，按住手柄拖拽；触摸端整行长按 500ms 后拖拽（短按仍为切换文档）。
- 落点：拖到其它笔记本分区内即跨笔记本移动（`reorderDocument` 支持）；拖到笔记本头行上/下方分别落入上一笔记本末尾 / 下一笔记本开头；笔记本行本身不参与拖拽（保留菜单上移/下移）。
- 兼容性：章节行行体无拖拽手势识别器，点击（含轻微移动的点击）始终解析为切换文档；手柄点击（按下即抬起）为空操作，由手柄内 `GestureDetector` 消费（pan 未确认时事件不落到行体）。
- 实现：`ReorderableListView`（buildDefaultDragHandles: false）+ 行引用数组把扁平索引映射回（笔记本, 位置），映射为纯函数 `reorderTarget`（sidebar.dart，单测覆盖）。

## 笔记本行图标

- 桌面端：平时显示文件夹 icon（展开指示不常驻）；hover 行时切换为箭头（未展开 `▸`，展开后旋转朝下 `▾`），点击整行展开/折叠。
- 触摸端：无 hover，保留箭头 + 文件夹双 icon（折叠状态必须常显）。
- 章节计数：标题后显示小字「N章」（如「小说 3章」），空笔记本不显示；折叠时同样可见，便于了解笔记本大小。

## 全书搜索（Book Search）

跨全部笔记本/章节的纯文本搜索（core/book_search.dart 纯逻辑 + ui/book_search_dialog.dart）。入口：侧边栏顶栏搜索 icon 或 `Ctrl/Cmd + P`（Notion 惯例；`Ctrl/Cmd+Shift+F` 已被沉浸模式占用）。

| 项 | 行为 |
|---|---|
| 对话框 | 居中偏上浮层（640×480 上限，窄屏自适应）；顶部搜索框 autofocus，250ms 防抖 |
| 匹配 | 大小写不敏感、忽略查询首尾空白；乱序返回按序号丢弃（只显示最新查询结果） |
| 分组 | 按章节分组：组头「笔记本 / 章节标题 + 命中数」，命中行显示上下文预览（不跨行，命中词 accent 加粗，截断加省略号） |
| 上限 | 单章 20 处、全书 200 处；截断时顶部计数行注明「仅显示前 N 处」 |
| 跳转 | 点击命中 → 关闭对话框 → 必要时切换文档 → 编辑器选中命中词并滚动到视口上 1/3 处（见 ui-editor.md §查找与替换） |
| 空态 | 未输入：「输入关键词，跨全部章节查找」；无结果：「全书没有找到「query」」 |
| 性能 | 每处理一章让出一次事件循环；坏文档（非法 Delta）跳过不阻塞 |

## Component Tree

```text
Sidebar
├─ HeaderBar（App Logo + BookSearchButton + NewNotebookButton）
├─ NotebookList（ReorderableListView，buildDefaultDragHandles: false）
│   ├─ NotebookTile（expand / collapse / ⋮）
│   │   └─ DocumentTile（选中态 / 拖拽手柄 ⋮⋮ / ⋮）
│   └─ NewDocumentButton
├─ InlineEditField（TextField / CancelButton / SubmitButton / ErrorText）
└─ EmptyState
```

## Page Entry Points

- 桌面：常驻左列；`Ctrl/Cmd + B` 切换显隐。
- Android：Drawer 滑入；打开 App 时若上次文档不存在则自动展开树。
