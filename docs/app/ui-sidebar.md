# 侧边栏（单书文档树）布局

Status: Draft
配套：ui-shell.md（管理层 + 工作区）、ui-settings.md（全局设置）、书内设置（本书设置对话框）

## Overall Structure

笔记本管理已独立为应用入口层（LibraryHome），侧边栏只服务**当前打开的这本书**：

```text
┌─────────────────────┐
│ [←] 我的小说   [🔍] [⚙] │  ← 顶栏：返回管理页 + 书名 + 全书搜索 + 本书设置
├─────────────────────┤
│ 第一卷               │  ← 分卷标题（本书设置开启分卷时按每卷章数生成）
│   · 第一章      ⋮    │  ← 当前文档高亮，⋮ 打开操作菜单
│   · 第二章      ⋮    │
│ 第二卷               │
│   · 第三章      ⋮    │
│ + 新建章节           │
├─────────────────────┤
│ ⚙ 设置               │  ← 全局设置入口（固定在底部）
└─────────────────────┘
```

层级规则：单书工作区内只有一层语义——章节列表；分卷是**视觉分组**（按每卷章数在树里插入「第 N 卷」标题），不动库、可随时开关。笔记本管理（新建/改名/删除/切换）在管理层 LibraryHome。

## Region Layout

| 区域 | 内容 |
|---|---|
| 顶栏 | 返回（回到笔记本管理页）+ 书名 + 全书搜索 + 本书设置（icon + tooltip） |
| 树区 | 当前书的章节；分卷开启时按每卷章数插入「第 N 卷」分组标题；当前文档高亮 |
| 操作菜单 | 每行 `⋮`：上移 / 下移 / 重命名 / 删除 |
| 拖拽排序 | 章节行：桌面端前置手柄（平时是章节 icon，hover 切换为拖拽手柄）；触摸端整行长按拖拽；分卷头不可拖 |
| 行内编辑 | 名称输入框 + 「保存名称」确认图标 + 「取消编辑」关闭图标 |
| 空态 | 无章节时的引导（「新建第一章」） |

## Interactions

| 输入 | 范围 | 行为 |
|---|---|---|
| 单击文档 | 树区 | 切换当前文档（先保存旧文档） |
| 顶栏 ← | 全局 | 返回笔记本管理页（先落盘当前缓冲，清空当前书；门控切回 LibraryHome） |
| 顶栏 ⚙ | 全局 | 打开「写作设置」对话框：写作目标 / 段落缩进 / 分卷 |
| 顶栏 🔍 / `Ctrl/Cmd+P` | 全局 | 打开全书搜索对话框（**只搜当前这本书**）；沉浸模式下快捷键不响应 |
| 拖动手柄 / 长按章节行 | 树区 | 章节拖拽排序（本书内） |
| `⋮` → 上移/下移 | 桌面 | 章节在本书内移动一位 |
| `⋮` → 重命名 | 桌面 | 行内变成输入框；Enter 或「保存名称」确认；Esc 或「取消编辑」取消 |
| `⋮` → 删除 | 全局 | 弹轻量确认条（「删除《第一章》？此操作不可恢复」确认/取消） |
| 树底部「+ 新建章节」 | 全局 | 点击**直接创建**，标题由 `suggestedChapterTitle` 顺着已有章节自动编号（全部为「第 N 章」式 → 最大序号 +1，沿用原数字风格；空书 → 第 1 章），不进入命名环节；想改名用 ⋮ → 重命名 |
| 空态按钮 | 全局 | 新建第一章 |

行内编辑与普通树行保持同高；异步写库期间保留编辑行，直到新行或新名称已就绪，避免章节在新增、重命名时发生高度闪烁。

删除确认条（非模态）：出现在编辑器区顶部，5s 无操作自动关闭（不删除）。

## 分卷（视觉分组）

- 配置在「写作设置 → 分卷」：`启用分卷` 开关 + `每卷章数`（1–500，默认 20）。
- 开启后侧边栏按每卷章数插入分组标题：第 1~N 章为「第一卷」，之后每 N 章一卷（如 5 章 / 每卷 2 章 → 第一卷、第二卷、第三卷）。
- 标题用中文数字（`第一卷`）；分卷头为非交互行，不影响拖拽落点映射（`reorderTarget` 视为 isHeader）。
- 关闭即恢复平铺，章节与数据不受影响。
- 持久化键：`volume.<notebookId>.enabled` / `volume.<notebookId>.chapters`（settings 表）。

## State Variants

- **Loading**：骨架行 ×4。
- **无书**：`currentNotebook == null` 时侧边栏不渲染（应用门控此时展示管理层）。
- **空章节**：引导「新建第一章」。
