# 侧边栏（文档树）布局

Status: Draft

## Overall Structure

```text
┌─────────────────────┐
│ 字在            [+笔记] │  ← 顶栏：App 名 + 新建笔记本按钮
├─────────────────────┤
│ ▾ 我的小说           │  ← 笔记本展开态
│   ▾ 第一卷           │
│     · 01-开端.md   ⋮ │  ← 当前文档高亮，⋮ 打开操作菜单
│     · 02-冲突.md   ⋮ │
│   ▾ 第二卷           │
│     · 03-转折.md   ⋮ │
│ ▸ 随笔集             │  ← 折叠态
│ ▸ 日记               │
├─────────────────────┤
│  空态：               │
│  「新建一本笔记本，    │
│   开始写」            │
└─────────────────────┘
```

层级规则：V1 只支持两层语义——笔记本（文件夹）内为文档；文件夹嵌套仅按文件系统展示，不承诺专门管理交互。

## Region Layout

| 区域 | 内容 |
|---|---|
| 顶栏 | App 名 + 新建笔记本（图标按钮，带 tooltip） |
| 树区 | 笔记本列表；展开显示文档；当前文档高亮主题色 |
| 操作菜单 | 每行 `⋮`：重命名 / 删除（文档与笔记本均支持） |
| 空态 | 无笔记本时的引导区块 |

## Interactions

| 输入 | 范围 | 行为 |
|---|---|---|
| 单击文档 | 树区 | 切换当前文档（先保存旧文档） |
| 单击笔记本行 | 树区 | 展开/折叠 |
| `⋮` → 重命名 | 桌面 | 行内变成输入框，Enter 确认，Esc 取消 |
| `⋮` → 删除 | 全局 | 弹轻量确认条（「删除《02-冲突.md》？此操作不可恢复」确认/取消）；笔记本删除级联删除文件夹 |
| 顶栏 `+` | 全局 | 弹出「新建笔记本」输入框（默认名「新笔记本」） |
| 新建文档 | 全局 | 树底部「+ 新建章节」按钮（或当前笔记本行的 `+`）；文件名默认 `新章节.md`，行内重命名 |
| 空态按钮 | 全局 | 新建笔记本并展开 |

删除确认条（非模态）：出现在编辑器区顶部，5s 无操作自动关闭（不删除）。

## State Variants

- **Loading**：骨架行 ×3。
- **Empty**：引导文案 + 主按钮。
- **重命名冲突**：文件名已存在 → 行内输入框显示错误态，不允许确认。
- **非法文件名**（含 `/` 等）：同错误态处理。

## Component Tree

```text
Sidebar
├─ HeaderBar（App 名 + NewNotebookButton）
├─ NotebookList
│   ├─ NotebookTile（expand / collapse / ⋮）
│   │   └─ DocumentTile（选中态 / ⋮）
│   └─ NewDocumentButton
└─ EmptyState
```

## Page Entry Points

- 桌面：常驻左列；`Ctrl/Cmd + B` 切换显隐。
- Android：Drawer 滑入；打开 App 时若上次文档不存在则自动展开树。
