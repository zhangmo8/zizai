# 侧边栏（单书文档树）布局

Status: Draft
配套：ui-shell.md（管理层 + 工作区）、ui-settings.md（全局设置）、书内设置（本书设置对话框）

## Overall Structure

笔记本管理已独立为应用入口层（LibraryHome），侧边栏只服务**当前打开的这本书**：

```text
┌─────────────────────────────────┐
│ [←] 我的小说 [+卷] [⧉] [🔍] [⚙]  │  ← 顶栏：返回 + 书名 + [+新建分卷](仅手动) + 视图切换 + 搜索 + 设置
├─────────────────────────────────┤
│ 第一卷    2 章             ⋮    │  ← 分卷头（自动：可重命名；手动：重命名/删除卷）
│   · 第一章                ⋮    │  ← 当前文档高亮，⋮ 打开操作菜单
│   · 第二章                ⋮    │
│ 第二卷    1 章             ⋮    │
│   · 第三章                ⋮    │
│ + 新建章节                     │
└─────────────────────────────────┘
```

层级规则：单书工作区内只有一层语义——章节列表；分卷把章节组织为分组。**自动分卷**是纯视觉推导（按每卷章数插入「第 N 卷」头，不写库）；**手动分卷**是真数据分组（`volumes` 表 + `documents.volume_id`），章节按卷归组并可跨卷移动，章节永远属于某卷（无「未分卷」）。笔记本管理（新建/改名/删除/切换）在管理层 LibraryHome。

## Region Layout

| 区域 | 内容 |
|---|---|
| 顶栏 | 返回（回到笔记本管理页）+ 书名 + [+ 新建分卷]（仅手动分卷 + 分卷展示）+ 分卷视图切换（分卷展示/平铺展示，仅分卷开启时显示，图标过渡动画 + tooltip）+ 全书搜索 + 本书设置（icon + tooltip） |
| 树区 | 当前书的章节；分卷开启时分卷展示：自动模式按每卷章数插「第 N 卷」头，手动模式按卷归组（卷 + 卷内章节）；当前文档高亮 |
| 操作菜单 | 章节 `⋮`：上移 / 下移 / 移动到分卷（仅手动，二级菜单列卷）/ 重命名 / 删除；分卷头 `⋮`：重命名（自动/手动）、删除卷（仅手动；连带删除卷内章节） |
| 拖拽排序 | 章节行：桌面端前置手柄（平时是章节 icon，hover 切换为拖拽手柄）；触摸端整行长按拖拽；分卷头不可拖。手动模式下拖到卷头边界 = 移入该卷末尾 |
| 行内编辑 | 名称输入框 + 「保存名称」确认图标 + 「取消编辑」关闭图标（章节与分卷复用同一机制） |
| 空态 | 无章节时的引导（「新建第一章」） |

## Interactions

| 输入 | 范围 | 行为 |
|---|---|---|
| 单击文档 | 树区 | 切换当前文档（先保存旧文档） |
| 顶栏 ← | 全局 | 返回笔记本管理页（先落盘当前缓冲，清空当前书；门控切回 LibraryHome） |
| 顶栏 ⚙ | 全局 | 打开「写作设置」对话框：写作目标 / 段落缩进 / 分卷 |
| 顶栏 ⧉ | 全局 | 分卷视图切换：分卷展示（卷分组）↔ 平铺展示（忽略分组）；图标过渡动画 + tooltip；持久化键 `sidebar.volumeView` |
| 顶栏 🔍 / `Ctrl/Cmd+P` | 全局 | 打开全书搜索对话框（**只搜当前这本书**）；沉浸模式下快捷键不响应 |
| 拖动手柄 / 长按章节行 | 树区 | 章节拖拽排序；手动分卷下落到卷头边界 = 移入该卷末尾，落到章节行上方 = 移入该章所在卷对应位置（`manualReorderTarget` 映射） |
| `⋮` → 上移/下移 | 桌面 | 章节在本书内移动一位 |
| `⋮` → 移动到分卷 | 桌面 | **仅手动分卷**：二级菜单列出所有卷，选中后章节移到该卷末尾 |
| `⋮` → 重命名 | 桌面 | 章节行内编辑 |
| `⋮` → 删除 | 全局 | 弹轻量确认条（「删除《第一章》？此操作不可恢复」确认/取消） |
| 分卷头 `⋮` → 重命名 | 桌面 | 自动模式：自定义名覆盖「第 N 卷」（存 settings，留空恢复）；手动模式：改 volumes 表卷名 |
| 分卷头 `⋮` → 删除卷 | 桌面 | **仅手动分卷**：确认后删除卷及卷内全部章节（不可恢复） |
| 手动模式顶栏「+ 新建分卷」 | 全局 | 手动分卷 + 分卷展示时显示；点击直接创建（默认名「第 N 卷」中文数字），可随后重命名 |
| 树底部「+ 新建章节」 | 全局 | 点击**直接创建**，标题由 `suggestedChapterTitle` 顺着已有章节自动编号（全部为「第 N 章」式 → 最大序号 +1，沿用原数字风格；空书 → 第 1 章）。手动分卷下新章节归入当前卷（当前打开文档所在卷 → 最后一卷 → 无卷时自动建卷），不进入命名环节 |
| 空态按钮 | 全局 | 新建第一章 |

行内编辑与普通树行保持同高；异步写库期间保留编辑行，直到新行或新名称已就绪，避免章节在新增、重命名时发生高度闪烁。

删除确认条（非模态）：出现在编辑器区顶部，5s 无操作自动关闭（不删除）。

## 分卷（volume groups）

配置在「写作设置 → 分卷」：`启用分卷` 开关 + `分卷方式`（自动 / 手动）。开启后顶栏出现**分卷视图切换**（分卷展示 / 平铺展示），可随时在两种目录视图间切换（纯视图偏好，不动数据）。

### 自动分卷（默认，纯视觉推导）

- 按`每卷章数`（1–500，默认 20）在树里插入分组标题：第 1~N 章为「第一卷」，之后每 N 章一卷（如 5 章 / 每卷 2 章 → 第一卷、第二卷、第三卷）。**不写库**。
- 卷头可重命名：自定义名（settings 键 `volume.<notebookId>.name.<n>`）覆盖「第 N 卷」；留空恢复。
- 不可新建/删除卷（卷由推导产生）。

### 手动分卷（真数据分组）

- 卷是真实数据：`volumes` 表（id / notebook_id / name / position）+ `documents.volume_id`。
- **章节永远属于某卷，无「未分卷」概念**。侧边栏按卷归组（卷序 → 卷内章节）。
- 卷管理：顶栏「+ 新建分卷」（手动分卷 + 分卷展示时显示）→ 直接创建（默认名「第 N 卷」中文数字）；卷头 `⋮` 菜单（重命名 / 删除卷）。
- **删除分卷 = 卷 + 卷内所有章节一并删除**（有确认对话框，不可恢复；无「回落未归卷」）。删除最后一个卷后列表可暂时无卷。
- 章节移动：`⋮ → 移动到分卷`（二级菜单列出所有卷，移入该卷末尾）；或拖拽——落到卷头边界 = 移入该卷末尾，落到章节行上方 = 移入该章所在卷对应位置（映射逻辑 `manualReorderTarget`，纯函数可单测）。
- **自动 → 手动切换**：一次性按当前每卷分组建真实卷并归章（幂等，已有卷则跳过；沿用自动模式的自定义卷名）。**手动 → 自动**：只改侧边栏分组方式，`volume_id` 数据保留。
- 新建章节归入当前卷（当前打开文档所在卷 → 最后一卷 → **无卷时自动创建一个卷**）。

### 数据层

- DB schema v5：新表 `volumes`（随笔记本 CASCADE 删除）+ `documents.volume_id` 列；迁移脚本 + 回放测试（test/core/migration_test.dart）。
- Db 方法：`listVolumes / createVolume / renameVolume / deleteVolume`（删卷清空其章节 volume_id）/ `setDocumentVolume / moveDocumentToVolume`（跨卷移动重排 position）/ `ensureAutoVolumes`（自动→手动一次性建卷归章）。
- 持久化键（settings 表）：`volume.<notebookId>.enabled / .chapters / .mode / .name.<n>`、`sidebar.volumeView`（分卷展示 grouped / 平铺展示 flat）。

## State Variants

- **Loading**：骨架行 ×4。
- **无书**：`currentNotebook == null` 时侧边栏不渲染（应用门控此时展示管理层）。
- **空章节**：引导「新建第一章」。
