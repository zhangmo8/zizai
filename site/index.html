Features

为长文写作而做

围绕「把一本书写完」而做：分卷、章节树、字数目标与版本留底。

所见即所得编辑器

富文本格式随手可得，选中文字即浮现工具栏，写完即是排版完成。

笔记本与章节树

多本作品并行，章节自由分卷排序，长篇结构一目了然。

沉浸模式

一键隐去侧边栏、工具栏与状态栏，屏幕上只剩你和文字。

每日目标与写作统计

按书设定当日字数目标，今日增量实时累计，删除不倒扣。

崩溃恢复与版本历史

自动保存 + 单文档版本留底，误删误改随时回到过去。

全书搜索与替换

跨章节查找角色与伏笔，替换先预览再落笔。

导入与导出

导出纯文本 / Markdown，支持章节编号与排版选项，投稿直接可用。

Install

安装提示

安装包为自行分发、未做商店签名，系统会多问一句，属于正常现象。

macOS 首次打开若提示「无法验证开发者」，请右键点击应用 → 打开；仍被拦截时到「系统设置 → 隐私与安全性」选择「仍要打开」。
Windows SmartScreen 提示时点击「更多信息 → 仍要运行」。安装向导按当前用户安装，不需要管理员权限；已装旧版时直接运行新版 setup 即可升级。
Android 首次安装需允许「安装未知应用」。覆盖安装即可升级，书稿与设置保留在本地数据库中。
